PROYECTO RESERVA CANCHAS

Abrir index.html para iniciar el proyecto.
No requiere servidor, base de datos ni frameworks.
Los datos se guardan de forma simple usando localStorage del navegador.

FUNCIONES DEL ADMINISTRADOR
- Crear canchas y asignarlas obligatoriamente a un usuario dueño.
- Crear y eliminar usuarios dueños.
- Crear y eliminar clientes.
- Usuarios/Dueños y Clientes se administran en páginas separadas.
- Ver y administrar todas las canchas y reservas.

CAMBIOS DE RESERVA:
- El cliente debe pagar para que la reserva quede confirmada.
- El cliente puede cancelar su propia reserva hasta el día anterior a la fecha reservada.
